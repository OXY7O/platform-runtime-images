# Dukungan

Gunakan GitHub Discussions untuk pertanyaan penggunaan dan ide, issue untuk bug yang dapat direproduksi, dan private vulnerability reporting untuk keamanan. Sertakan release, workflow SHA, log yang sudah disanitasi, serta langkah reproduksi.

Repository ini merupakan verification fixture; ketersediaan kode bukan jaminan dukungan operasional atau izin deployment.
